# 📈 Virtual Stock Market Simulator

A full-stack **Virtual Stock Market Simulator** that allows users to practice trading stocks in real-time market conditions without financial risk. The platform uses live market data powered by **yfinance API**, providing a realistic trading experience with portfolio tracking, analytics, and transaction history.

---

## 🚀 Features

- 📊 Real-time stock data using **yfinance**
- 💰 Buy & sell virtual stocks with simulated balance
- 📁 Portfolio management with profit/loss tracking
- 📉 Interactive stock charts
- 🧾 Transaction history (buy/sell records)
- 📈 Market watchlist for tracking favorite stocks
- ⚡ Responsive and modern UI with React
- 🗄️ Persistent storage using MySQL

---

## 🛠️ Tech Stack

### Backend
- Java 17+
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL

### Frontend
- React.js
- JavaScript (ES6+)
- CSS3
- Axios (API calls)

### Data Source
- yfinance (Yahoo Finance API wrapper)
